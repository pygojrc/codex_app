# `.ms` Agent 工作区

本目录保存 ChatGPT Adapter 的当前状态、规则、ADR、任务文档和运行记录。

读取顺序：

1. `../AGENTS.md`
2. `.ms/README.md`
3. `.ms/rules/README.md`
4. `.ms/CURRENT.md`
5. `.ms/CONTEXT.md`
6. `.ms/adr/`
7. 当前任务文档与源码

目录职责：

- `rules/`：当前生效规则。
- `adr/`：长期架构与流程决策。
- `tasks/`：任务计划、分析和 running docs。
- `knowledge/`：可复用经验，不覆盖规则。
- `templates/`：文档模板。
