# ADR-0001：独立项目根与可复现输入

- 状态：Accepted
- 日期：2026-07-23

## 背景

历史 Linux 适配分散在上级项目的多个 `version_*` 目录，并复用外部
`/data/opt/codex-gui` runtime。新版本还新增 Electron 42.3.0、sidecar 和 native
module 兼容工作，继续跨目录取文件会使构建输入难以复现。

## 决策

- 使用 `chatgpt_adapter/` 作为独立 Git 项目根。
- 所有输入副本、下载、源码、文档、native 构建环境和产物都位于项目内。
- Git 只跟踪可复现的源码、配置、锁文件、manifest 和校验和；大型二进制在项目内
  保存但被忽略。
- 构建流程不得依赖上级旧版本目录和外部已安装 Electron runtime。

## 后果

- 项目可单独复制、审计和重建。
- 本地磁盘仍需保存较大的 DMG、Electron runtime 和构建产物。
- 大文件本身不受普通 Git 保护，必须依靠来源 manifest、SHA256 和重建脚本。
